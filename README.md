# Masuk HRM

A lightweight Human Resource Management (HRM) web app prototype for **Masuk**.

## Features

- Add and view employees
- Mark daily attendance (Present/Late/Absent)
- Submit leave requests
- See quick payroll summary (employee count + total monthly payroll)

## Run locally

No build step required.

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser.
